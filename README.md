Beyond Revenue: Retail Delivery and Customer Analytics
Project Overview
Revenue alone doesn't tell the full story of a business.
In this project, I used a simulated retail orders dataset to investigate delivery failures, customer retention, and estimated contribution. I worked with Excel, Python, and SQL Server to explore the data and answer business questions.
Tools Used
- Excel: Data review, cleaning, and analysis.
- Python: Data cleaning and exploratory data analysis.
- SQL Server: Querying data to investigate business performance.
Business Questions
- How many orders failed, and what was the delivery failure rate?
- What do delivered sales and estimated contribution tell us about performance?
- How many distinct customers appear in the dataset?
- What can the data reveal about delivery performance and repeat customers?
Key Findings
- 250 orders were analysed.
- 24 orders failed, representing a 9.6% failure rate.
- The dataset contained 87 distinct customers.
These figures describe the simulated dataset used in this project.
Why This Project Matters
Businesses need to look beyond sales figures. Delivery failures, repeat purchasing, and contribution estimates can help identify areas that require attention.
This project allowed me to practise using different data tools to investigate the same business problem.
